# Brand v1.1.0 release

This directory contains the fixed, versioned Brand v1.1.0 assets.

## Immutability

Once published, this release must never be modified, overwritten, or replaced.
Any future changes must be published in a new version directory.

## Contents

- `brand.css`: shared styles and components
- `tokens.css`: design tokens only
- `brand.js`: theme handling, logo symbols, and command palette
- `logo/`: SVG logo marks
- PNG and SVG icons: favicon and app icons
- `SHA256SUMS.txt`: SHA-256 checksums for all 12 release assets

## Verification

Use the SHA-256 values in `SHA256SUMS.txt` to verify that the release assets have not changed.
