The idea

Signal & Ink

Ink is the writing: deep navy surfaces and quiet type that let content lead. Signal is the network: a single teal that marks whatever you can act on. Your work is wireless systems, scheduling and networks, so the identity borrows from that world without turning into a circuit-board costume.

Ink does the talking

Navy-tinted neutrals carry almost every pixel. Signal teal shows up once or twice per screen: the main button, the active link, the focus ring.

Engineer's detail

Labels, dates and figures use the mono face with real units: 2026-11-17, 4 min read, M=16 antennas. Small, exact, and recognisably yours.

The same everywhere

One token file feeds all three sites. A button in the admin is the same button on the portfolio, so a visitor never wonders if they left your site.

Logo

An r with a signal behind it

The mark is a lowercase r, your initial, followed by a dot that radiates two arcs. It reads as wireless without drawing an antenna. The wordmark splits your name into its two halves, rabs in ink and rabi in signal.

Sizes

Rules

  • Clear space. Keep at least the width of the r's stem free on every side of the mark.
  • Small sizes. Below 28 px use the simplified mark with a single arc. It keeps the r legible in tabs and bookmarks.
  • Colour. The tile is always Signal with the glyph in Signal Ink. On a Signal background use the Ink tile instead. Never recolour the arcs.
  • Sub-brands. Notes and admin add a mono suffix after the wordmark, written / notes and / admin. The portfolio takes no suffix.

Navy neutrals, one teal, one spark

Typography

Three voices, one scale

Bricolage Grotesque gives headings a confident, slightly quirky edge. Instrument Sans keeps long reading calm. JetBrains Mono carries the engineering detail. All three load from Google Fonts, which the blog already uses, with system fonts as the fallback.

Use the kit

Three lines in any page

Add the fonts, the stylesheet and the script. The script applies the saved theme before the page paints, adds the logo symbols, and wires up the theme buttons and the command palette.

<head>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:wght@500;600;700;800&family=Instrument+Sans:wght@400;500;600;700&family=JetBrains+Mono:wght@400;500;600&display=swap">
<link rel="stylesheet" href="https://brand.rabsrabi.com/v1/brand.css">
<script src="https://brand.rabsrabi.com/v1/brand.js"></script>

Logo

Put <svg class="mark"><use href="#rs-mark"/></svg> before the wordmark inside an element with class lockup.

Theme switch

Any buttons with data-theme-choice="auto|light|dark" work. The choice is stored for all of .rabsrabi.com.

Own components?

Load tokens.css instead of brand.css to get only the colors and type. Set window.RABS_BRAND = {palette:false} to keep your own palette. The page gets a themechange event.

Palette entries

Call RabsBrand.palette.setItems([{group, label, hint, href}]) to add this site's own pages and notes. Links to the three sites are built in.

Rollout

How this reaches the three sites

Nothing has been changed in your repositories. Once you approve this direction, the work goes in this order, so each site keeps working at every step.

  1. Publish the brand kit

    This repository, served from brand.rabsrabi.com. The v1 folder holds brand.css, brand.js for the theme switch and command palette, the logo files and the favicon set. Done.

  2. Rebuild the notes blog

    Swap its styles for the shared tokens and give its CMS a real dark mode.

  3. Restyle the central admin

    Apply the brand and turn the "Coming soon" cards into real links to blog and portfolio management.

  4. Move the portfolio onto the tokens

    Keep its hero and lab as they are, and replace its separate stylesheet values with the shared ones. Remove the duplicated folder found in the audit.

  5. One sign-in for everything

    A separate follow-up: make auth.rabsrabi.com the single login that the blog's editor trusts.

Decisions made
Palette, type and logo

Signal & Ink with teal, amber and blue accents, the three typefaces, and the r-with-signal mark.

The blog is rabsrabi / notes

It replaces the name RabiNotes in the header, page titles and footer, so your own name carries the brand.

Fonts from Google Fonts

Quickest to ship. Self-hosting the font files can follow later for privacy and speed.

Still open

The blog's sign-in Worker is not in any repository, so the shared login step waits until its source is available.
